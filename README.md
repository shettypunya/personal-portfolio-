# Punya Shetty – Personal Portfolio Website

A responsive personal portfolio built using HTML, CSS, and JavaScript for the Codomax Full Stack Web Development internship task.

## Files
- `index.html` – page structure and portfolio content
- `style.css` – colours, layout, and responsive design
- `script.js` – mobile menu, current year, and contact form interaction

## Run the project
1. Extract the ZIP file.
2. Open the `punya_personal_portfolio` folder.
3. Double-click `index.html`, or open the folder in Visual Studio Code and use Live Server.

## GitHub submission
1. Create a GitHub account if you do not already have one.
2. Create a new public repository, for example `personal-portfolio`.
3. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
4. Open the repository and copy its URL.
5. For a live website, open the repository's **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save. GitHub Pages will provide a website link after deployment.

## Contact form note
The contact form uses a `mailto:` link. It opens the visitor's email application; it does not send or save messages on a server. Replace the sample email address in both `index.html` and `script.js` with your own email address.
