
Punya Shetty – Personal Portfolio Website
A responsive personal portfolio website created using HTML, CSS, and JavaScript as part of the Codomax Full Stack Web Development internship.
About the Project
The website introduces Punya Shetty and presents an overview of her background, education, technical skills, projects, and contact information. It is designed to provide a simple and accessible experience across desktop and mobile screens.

Home section with a brief introduction
